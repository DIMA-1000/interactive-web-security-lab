Validation rules


Name: 1–80 characters after trimming.
Age: integer from 18 to 120.
Email: a basic format check, maximum 254 characters.
Unknown fields are rejected.


Malformed JSON returns 400; invalid fields return 422.
A real API must enforce these rules on the server.
