Why parameters matter


Concatenation puts input into SQL syntax. With genuine database
parameter binding, the query and values are sent separately.
The input remains a value, even when it contains SQL characters.


In a real backend, use the database driver's parameter API.
Displaying a question mark alone does not make a query secure.
