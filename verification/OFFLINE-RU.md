# Офлайн-режим
Основа: Interactive-Web-Security-Lab-final-visual(1).zip. Дизайн и существующие CSS/JS сохранены без изменений. GitHub не изменён.

Добавлены sw.js, assets/offline.js и assets/offline.css. В шесть HTML добавлены ссылки на эти файлы и worker-src self в CSP. Другие ограничения CSP сохранены.

Первое открытие по HTTPS сохраняет 21 файл, включая все шесть страниц, лаборатории, JS/CSS, баннер и favicon. Готовность обозначена Ready for offline use. Сайт доступен в том же браузере и профиле без подключения. Инкогнито и очистка данных не сохраняют эту гарантию; браузер также может освобождать хранилище.

Используется согласованный сохранённый комплект, а не смешивание свежих страниц со старыми скриптами. При открытии, возвращении на вкладку и появлении сети проверяется новый Service Worker. SHA-256 проверяет каждый файл: неполный или смешанный комплект не активируется. Старый кэш сохраняется до успешной активации. Полностью скачанное обновление предлагает Update, после нажатия вкладка перезагружается. Другие открытые вкладки лучше закрыть перед обновлением.

Важно при каждом дальнейшем изменении сайта: перегенерировать sw.js, иначе браузер не обнаружит новую сборку. Из папки проекта запустить python verification/rebuild-offline.py и коммитить новый sw.js вместе с изменёнными файлами. Либо передать проект для подготовки нового sw.js. Скрипт требует Python только при подготовке релиза, не для работы сайта. Сначала публикуется весь комплект одним коммитом; если CDN временно отдаёт смешанные версии, установка отклоняется и повторяется позже.

Тестирование: синтаксис JS; целостность manifest; существующие визуальные CSS/JS побайтово совпадают с ZIP; локальные ссылки существуют. Node-модель Service Worker подтвердила полную установку, офлайн-выдачу страниц, границы origin, активацию и сохранение старого кэша при несовпадении файла. Это НЕ проверка настоящего браузера: lifecycle, CSP enforcement, кнопки, offline DevTools, layout/mobile остаются неподтверждёнными. Браузер среды недоступен. Не выдавать сборку за browser-tested.

Для публикации без ZIP: добавить 3 новых файла и заменить 6 HTML; сохранить структуру assets. verification — отчёт и инструмент подготовки, не обязателен для работы сайта.
