# English / Norsk и оформление имени
Три нажатия на надпись Frederick на главной включают норвежский Bokmål на пять минут. Ещё три нажатия выключают его сразу. Нет ограничения на интервал между нажатиями. Срок хранится в localStorage и сохраняется при переходах между шестью страницами; другие вкладки синхронизируются. При возвращении на вкладку срок перепроверяется. В фоне браузер может задерживать таймер; при возвращении английский восстанавливается. При блокировке localStorage режим работает только в текущей странице. Поддерживаются click на touch и мыши, Enter/Space для клавиатуры.

Переведены видимые статические тексты всех шести страниц, подсказки, заголовки, кнопки, результаты/ошибки лабораторий и статусы офлайн-режима. Имя Frederick, имена людей, учебные ID, JSON-ключи, код SQL, HTTP-коды и пользовательские входные данные не переводятся. Никакие API перевода не используются: словарь локальный, работает офлайн, CSP не ослаблена.

Цвета имени сохранены: исходный белый и var(--green). Добавлены только тонкие тени для глубины. Ранее добавленные отступы против обрезания V сохранены. Сканер и его ограничения сохранены.

Добавлен assets/language.js; подключён в шести HTML. Изменён assets/index-0.css; пересобран sw.js. Проверена полнота словаря статических текстов шести страниц; JS проходит node --check. Test-language.cjs в модели DOM проверил три нажатия, повторные три нажатия и истечение пяти минут с восстановлением исходного английского текста. Проверены SHA-256 всех файлов офлайн-манифеста. Настоящий браузер/touch/runtime, оформление и CSP по-прежнему не проверены из-за отсутствия браузера среды.
