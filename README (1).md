## 🇬🇧 🇳🇬 English

<img src="app-icon.webp" alt="AntiStress Trade icon" width="120">

**An Android application designed to make visually intense trading screens easier to manage.**

AntiStress Trade places a movable vertical overlay over part of another application's screen. Users can cover distracting price movements and bright red or green areas with a plain color or a decorative background, while leaving the rest of the screen visible.

**Localization:** The application supports 43 languages, with extensive localization work to improve usability and make the application easier to use for users in different languages.

## Development and testing status

A working development build has been uploaded to Google Play Console and is undergoing testing ahead of a public release. The screenshots below show the application running on an Android device.

Testing and refinement are ongoing. This showcase does not claim that the application is free of all bugs or that it has received final Google Play approval.

**Source code is private.** This public repository contains the application presentation, icon and screenshots, rather than the Android source project. Keeping the implementation private is the developer's decision.

## Basic features shown in this showcase

- A vertical overlay displayed over other applications with Android overlay permission.
- Start and stop controls for the overlay.
- Movable placement on the left or right side of the screen.
- Color and lightness controls.
- Plain backgrounds and decorative themes, including beach, forest and cat designs.
- Help, language and privacy controls available from the main application screen.

## Additional features and subscription access

Financial applications often display rapidly changing numbers, bright colors and flashing visual elements. AntiStress Trade offers features intended to reduce visual overload and help users manage distracting areas while using these applications.

The screenshots show only a selection of the simplest features. Additional features are available through a subscription and are not disclosed in this public showcase. Their implementation and the application source code remain private.
